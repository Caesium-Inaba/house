# 《House》六项改进 · 语言学与教育深化

## 研究结论（标注可信度）

- **童年特质（CK3 wiki/ck3db 1.20 权威）**：五种为 bossy/charming/curious/**pensive**/rowdy（我们的 peculiar 有误，改 pensive）；属性加成：专横 +1管/+1武、可爱 +1谋/+1外、好奇 +1外/+1学、沉思 +1学/+1管（修体质？查询显示 pensive +1学+1管）、闹腾 +1武/+1谋。
- **成年转换（社区通识，中置信度）**：专横→傲慢、可爱→合群、好奇→狡诈、沉思→冷静、闹腾→暴怒；16 岁移除童年特质并入列。
- **CK3 性格抉择点位（Steam 讨论佐证）**：童年期多次性格事件；我们适配为 **9/12/15 岁三次「性情抉择」**，候选人一个受监护人性格影响（跟随师长的天性）、一个随机（优先与既有特质成对）；强迫改特质将调用**压力 API 占位（仅留接口不实现）**。
- **官方中文译名（Steam 对照表）**：天才/聪慧/敏锐/迟钝/笨拙/痴呆；健壮/海格力斯/纤维体量（dedicate=纤弱、脆弱、衰弱）；勇敢/怯懦/冷静/暴怒/忠贞/色欲/勤勉/懒惰/慈悲/慷慨/贪婪/合群/害羞/诚实/狡诈/谦卑/傲慢/公正/专断/耐心/急躁/节制/暴食/轻信他人/多疑/狂热/愤世嫉俗/野心勃勃/安于现状/宽宏大量/睚眦必报；童年：专横/可爱/好奇/沉思/闹腾；教育 1-4 级全名采录（天真的绥靖者→幕后操控人等 20 条）；Dynasty 官方译名 = **宗族**，Renown = **宗族威望**（10 级威望等级表证实），传承=宗族传承。

## 实施步骤

1. **i18n 解耦（第一批）**：新增 `src/house/i18n.py` + `src/house/data/locales/zh.json`：事件模板、属性名、健康档、文化、性别法、传承树文案、称谓、特质全表名 —— 统一 `t(key, **params)`。core 的 8 处 add_log/事件加 `_KEY_+params`（事件 dict 增加 `key`/`params` 字段，旧 zh 文本保留、旧档兼容 save v4→实际维持版本号增加 events key 即可）；`save.default_name`、presenter 的称谓/合理性文案全部走 i18n；traits.json 剥离 `name`（名字走 `trait.<id>` 键 → 应用官方译名并**替换 peculiar→pensive** + 修正童年加成）。WebUI 新增 `webui/src/i18n.ts`（先覆盖 TopBar/面板段标/弹窗标题按钮/toast 等主要标签，服务端保留 `lang` 参数位，本批默认 zh）。
2. **推荐名字池去重**：`genetics.pick_name` 与 presenter 的命名建议池排除同姓氏兄姐弟妹（同父或同母、含已故）的重名；手动输入不约束。
3. **世数（罗马数字）**：presenter 按同名同宗族成员出生序计算 rank N，N≥2 时名字显示 `XX <罗马数字>`（如 布赖什二世）；数字用小型 to_roman 工具；旧档无需改动（动态计算）。WebUI 各处展示人物名统一走一个 `displayName()`。
4. **家族树去配偶**：buildLayout 全节点单人化；子女挂靠父系（母系婚姻挂母），跨支不再画婚姻连线；世代标尺保留。连线更清爽，为多代大谱系减负。
5. **教育事件深化**：
   - 9/12/15 岁「性情抉择」（world.trait_queue 新队列；WebUI 弹窗，AI 自动选监护人侧选项）—— 候选特质生成规则见研究结论；写年度 `grow_children` 分段。
   - 16 岁定型：按上表童年特质转换 + 发事件「X 获得特质 Y（承童年 Z）」。
   - `src/house/core/stress.py`：`add_stress(world, char_id, amount, reason)` 存根（no-op + 注释标注压力系统待实现）；在抉择/强制改特质/监护改质心动事件处调用。
   - trait_queue 展示：编年史待办横幅 + 右栏卡（复用教养礼的 pending 模式）。
6. **测试与回归**：web_smoke 增性情抉择用例；smoke 全绿；30 年模拟抽名字完整性（特质 ID 全部能 ping 通 i18n，不会流出英文键码）；`bun run build` + 浏览器验收新面板/横幅/树改版；README 更新（译名表来源 + 童年特质映射说明）。
