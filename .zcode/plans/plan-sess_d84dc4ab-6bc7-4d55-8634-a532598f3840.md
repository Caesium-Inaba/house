# 《House》游戏性 CK3 化 · 第一批

## 依据（CK3 wiki 1.20 核查结论）

- **已对齐（保持）**：受孕 = 双亲生育力均值 × 4.75/月；出生健康 男 4.5–4.9 / 女 5.0–5.4；25 岁起 7.5%+2.2%/年掉 −0.125 健康；45 岁起 10%+1.5%/年掉 −1 勇武；健康档位阈值（<0 濒死 / 0-1 垂危 / 1-3 差 / 3-5 尚可 / 5-7 好 / 7+ 极佳）；女 46 岁绝经。
- **修正**：男年龄曲线拆 41-45:0.8 / 46-50:0.8；双胞胎 1%→**3%**；新增**男性子女上限 9（每额外配偶 +2）**； FECUND（多产）使生育衰减起点 **+5 岁**；分娩风险改为**与母亲健康、产次挂钩**（wiki 定性 + 适配曲线，标注可调）。
- **重做**：教育判定 = CK3 原始公式（年度 `+2` 成功率 = `(60+成功因子)/(100+成功因子+失败因子)`；成功因子：孩子天才 20/聪慧 15/敏捷 10、童年特质匹配 +20/不匹配 −20、监护人技能×0.4+学识×0.2、监护人天才 15/聪慧 10/敏捷 5；失败因子：孩子 slow 10/stupid 15/低能 20/**近亲孳息 20**、无监护人 +20；16 岁按得分给 ★~★★★★（0-7/8-12/13-17/18+））。
- **特质数值**：按 wiki Traits 页采录（本次已抓到大部分：勇敢 +2武/+3勇、胆怯 −2武/+2谋/−3勇、贞洁 +2学/−25%生育、好色 +25%生育、勤勉 +2外/+3管/+3学、节制 +0.25 健康、谦卑/傲慢对内 ±15，同特质 +10/异特质 −10 等），写入 traits.json；好感模型去月度衰减（CK3 无衰减），改事件式（婚配 +15、监护 +5/+15）。
- **传承树成本**：首级 500，后级 ×1.5（500/750/1125/1700/2500）—— 中可信度，标注可调。

## 本批不做（下一批候选，需要先铺事件引擎）：压力系统（0-400，已查到权威表）、生活方式（焦点+XP 表）。

## 实施步骤

1. **core 底盘**（balance.py/traits.json/traits.py）：性格特质数值化（约 24 个，含 attrs/fertility/health/opinion）、先天特性表按 CK3 精确按键等级（放弃线性 per_level 模型改显式表）、生育曲线/双胞胎/男上限/多产/分娩风险。
2. **教育系统 core**（genetics.py + models.py）：`childhood_trait`（6 岁 roll）、`education_focus`、`education_score`、`guardian`；`grow_children` 改为年度判定（生日 roll +2）；`finalize_education` 按得分定性；近亲孳息参与失败因子；`world.tutoring_queue`（玩家血亲 6 岁入队，AI 孩子自动：焦点=童年特质对应，监护人=同族最高相关技能成人）。
3. **订婚 + 母系**（marriage.py/fertility.py）：`arrange_betrothal`（双方 ≤15 岁皆可订，带 patrilineal 标记）；月度结算检查到 16 岁自动履约成婚（事件「履行婚约」）；婚配候选扩展含**外籍 6-15 岁儿童**（订婚池）；`can_marry` 增加订婚约束（有婚约者不能与他人成婚）。
4. **王朝传承**（models.Dynasty + 新 legacy.py）：`legacies: dict[树id→级]`；5 树（血脉/武略/律法/谋略/荣光）× 5 级；血脉树 +10%/+5% 生育力、家族健康 +0.5、生育衰减+5、近交抗 +25%；武略 +勇武/健康；律法 +威望/金钱%；谋略 +谋略；荣光 +威望%/好感。效果聚合为 `family_modifiers(world, dynasty)` 单点函数，被 fertility/genetics/health 调用；购买扣威名。
5. **presenter/server/types 扩展**：教养礼弹窗（选定焦点 + 指派监护人，默认推定高亮）、婚配沙龙双 Tab（联姻/订婚）+ 母系勾选、右栏传承面板（5 树进度 + 购买）、人物卡新增童年特质/焦点/监护人/教育得分/婚约显示、编年史新事件类型（教养/婚约/传承）接入筛选与图标。
6. **测试与校准**：存档升 v3（新字段 default 兼容 v2）；`tests/smoke.py` 保持全绿（TUI 不回归）；`tests/web_smoke.py` 增教养、订婚履约、购买传承用例；跑 `tools/sim_balance.py` 校准 300 年人口曲线（双胞胎 3% 的人口上浮由上限节流兜底）；`bun run build` + 浏览器逐画面验收 + 数值抽查（同 seed 对比改造前后出生特质分布）。
