# House · 王朝编年史

CK3 式中世纪家族王朝模拟器：1066 年的波希米亚，执掌普热梅斯利德家族，
看着血脉出生、起名、联姻、生育、衰老、继承 —— 别让家族绝嗣。

数值与机制剑定 CK3 wiki 1.20：受孕公式（双亲生育力均值 × 4.75/月）、出生健康
（男 4.5-4.9 / 女 5.0-5.4）、健康与勇武衰减曲线、教育判定（童年特质 → 教育得分
→ 监护人公式 `(60+S)/(100+S+F)`，16 岁按得分定 1-4 环）、双胞胎 3%、男性 9 存活
子女上限、近亲婚禁令（默认表亲可婚）、宗族传承树（血脉/武略/律法/谋略/荣光 ×
5 级，宗族威望消费）、订婚与母系婚姻。

**多语言与官方译名**：所有面向玩家的文案经 `src/house/data/locales/zh.json`
（i18n `t(key)`），core 事件以 `key+params` 结构化存储（旧档文本兼容）；
特质中文名采录 CK3 官方汉化（Dynasty=宗族、Renown=宗族威望、genius=天才、
imbecile=痴呆、ambitious=野心勃勃 等，来源：Steam 官方中文对照表 2551527752）。

**命名与世数**：命名礼只为本宗族新生儿举行（推荐名自动避开同父母手足重名，
手动输入不约束；所有新生儿不限宗族，都可在人物栏中改名）；世数只数做过家主
的同名者，按继位顺序标罗马数字（如「雅罗米尔II世」，未继位者不计入、不展示
「世」字）；家族树为纯血缘图（不展示配偶，子女按父系/母系挂锚，可聚焦不同
宗族域、外嫁支只展示这一代并挂其家族盾徽可点击跳转、节点可展开/合并）。

**童年成长（CK3 事件化）**：6 岁童年特质（专横/可爱/好奇/沉思/闹腾，含 1.20
实机属性加成）→ 9/12/15 岁三次「性情抉择」（候选人：师长言传——随监护人天性，
率性而为——随机成对；抉择会给监护人记压力，压力系统仅留 API 存根）→ 16 岁
童年特质按表转换为性格特质（专横→傲慢、可爱→合群、好奇→狡诈、沉思→冷静、
闹腾→暴怒，社区通识表）。

两种前端，共享同一套核心逻辑（`src/house/core/`）：

| | 命令 | 适合 |
|---|---|---|
| **横屏 TUI**（Textual） | `uv run python main.py` | 终端党 |
| **桌面 WebUI**（FastAPI + React） | `uv run python webui.py` | 电脑端日常游玩 |

## WebUI

「烛光宫廷」暗色主题。首次运行前需构建前端一次：

```bash
cd webui
bun install
bun run build
cd ..
uv run python webui.py            # 起服后自动开浏览器，默认 http://127.0.0.1:8000
```

前端热更开发（改 React 代码即时生效）：

```bash
# 终端 1
uv run python webui.py --dev --no-open     # 后端 API，开放 CORS
# 终端 2
cd webui && bun run dev                    # Vite 热更，http://localhost:5173
```

### 玩法要点

- **时间**：推一旬 / 推一年 / 自动推进（`Y` / 按钮）；**五档流速**（顶栏 Ⅰ-Ⅴ，自动推进一旬间隔 1300→80ms）；`空格` = 暂停 / 开始。
- **事件浮窗**（CK3 式）：命名礼 / 教养礼 / 性情抉择弹出后**时间照常流动**，浮窗可拖拽、多事件并存、窗外无遮罩；**两个月内未处置会自动落定**（命名用推荐名、教养用推定方向、择性用「师长言传」，没有推荐则随机）。
- **编年史**（中栏）：结构化事件流，按类型筛选（有孕 / 诞生 / 联姻 / 婚约 / 开蒙 / 成年 / 离世 / 继承 / 传承），记事里的人名可点击查看（呼出人物栏）。
- **人物栏**（左侧全高抽屉，CK3 布局）：大头像 + 配偶位（无配偶且可婚时显示「＋」呼出婚配沙龙）；领主与第一继承人列（带玩家与他们的好感、被看人对领主的好感）；名字 · 岁数 · 健康心 · 与领主的亲属关系；宗族盾徽点击查看家族树；六维 pips / 产业 / 健康 / 身孕；先天血脉区分显性与隐性携带者；心性 chips 含性取向；监护关系（同一位置显示监护人/被监护人）；新生儿改名；右上角大头针（标记人物，暂无效果）与关闭。调试模式下额外有「让其身亡」。
- **家族**（右栏）：**王朝传承**（5 树等级 + 威名购买）、继承人预览、眷属上限（1/1）、天下人口（软上限 90 / 硬上限 160）、诸家威名、在世成员名录、待教养队列。
- **婚配沙龙**（`M`）：**联姻**（家主）与**订婚**（为 6-15 岁孩童，到 16 自动成婚，可选**母系婚姻**保住血脉）双页签。
- **家族树**（`T`）：全屏可缩放谱系，世代标尺、逝者标注、节点展开/合并、宗族域切换（外宗族盾徽跳转+镜头对准、「回到家主」一键返回）。
- **终局**：家族绝嗣时展示存续之年、传承世代、生卒婚配统计；`?over-preview=1` 可随时预览该画面。
- **调试模式**：`uv run python webui.py --debug` 额外开放「指名杀人」端点（死因「调试」，人物栏内为「让其身亡」按钮）；**自尽**在正常与调试模式下都可用（立即结束自己生命并触发继承）。exe 打包不启用调试模式。

### 打包（PyInstaller，可选）

WebUI 单文件 exe：

```bash
cd webui && bun install && bun run build && cd ..
uv run pyinstaller HouseWebUI-V0.1.0-alpha.spec --noconfirm
# 产物：dist/HouseWebUI-V0.1.0-alpha.exe（双击即玩，自动开浏览器；存档生成在同名 saves/ 目录）
```

spec 会把 `src/house/data`（数值/名字/语言包）与 `webui/dist`（前端产物）一并打入，
服务端从 `sys._MEIPASS` 读取；TUI 打包沿用 `houseV0.0.2-alpah.spec`。

## 技术结构

```
src/house/core/   游戏逻辑（纯 Python，无 UI 依赖）：sim 生育 婚姻 遗传 健康 继承 存档
src/house/web/    FastAPI 桥：server.py（API）+ presenter.py（快照适配层，前后端唯一边界）
src/house/ui/     Textual TUI
webui/            React + TS 前端（bun 管理；zustand 状态；程序化纹章；SVG 家族树）
```

存档格式 v3：在 v2（结构化 events）上增加 head_history（继位顺序表，供世数计算）；
旧档读取自动回退合成，双向兼容。数值调校见 `tools/sim_balance.py`；开发记录见 `WORK1.md`。
